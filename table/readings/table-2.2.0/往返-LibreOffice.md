`table/.venv/bin/python tools/lo_roundtrip.py`：取 `golden_cases.json` 里全部成功的 table.build 金样（68 例），经进程入口跑出 xlsx，
交 LibreOffice 打开、`calculateAll()` 重算、另存 xlsx，再按包自己的排布（`xlsx_writer._plan`：数据行、合并行、小计行、合计行各在哪一行）

覆盖到的 2.2.0 写法：格公式（乘式、引用本表别行、引用别表，`CEILING(…,1)` 由工具补全步长）、整本工作簿的依赖次序；
分组（按一列、按层级）、小计（`SUBTOTAL`）、合并行（明细之和、合并后按本列公式重算的 `ROUNDUP`）、合计只算看得见的行；
跨表汇总（等值匹配的 `SUMPRODUCT`，改名、调序以后公式里是新表名）、派生表（引用各来源格的求和）、300 行追加后的范围。

要点：
- T5-03 / T8-01：螺栓 M10×25 合并行的下料数量在 LibreOffice 重算后是 605（合并后再取整），不是 606；总重合计 2116.8。
- T9-08：标准件螺栓 M10×25 是 `='01立柱'!G7+'02横梁'!G7` = 6224（各分部取整后相加）。
- T8-03：明细招待费改成 9000 的那一例，预算表招待费实际 16800、汇总表销售部 51300，重算一致。
- 读数的方法改了一处：2.1.0 的读回假设第 i 个数据行在 Excel 第 i+2 行；有分组、合并以后不成立，改为按包的排布取行。
  改的过程中发现并修正了 2.0.x 起的一处：从表模型再规范化时，百分比列被再除了一次 100（见 README）。
