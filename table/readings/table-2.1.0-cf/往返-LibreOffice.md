# Excel 往返读数（LibreOffice 无头重算读回逐格比）

> 执行令《首发后-table包2.1.0》§三；#710 §6.0。2026-11-12，LibreOffice 24.2.7.2，容器内无头。

## 值（逐格比）

`table/.venv/bin/python tools/lo_roundtrip.py`：对 `golden_cases.json` 里全部成功的 table.build 金样（45 例），经进程入口跑出 xlsx，
交 LibreOffice 打开、`calculateAll()` 重算、另存 xlsx，再用 openpyxl 读回重算后的值，与表模型逐格比（数据行与合计行；数按十进制比到 1e-9 的相对误差，文字照字比，日期比到日，空对空）。

| 例数 | 比的格数 | 不一致 |
|---|---|---|
| 45 | 1968 | 0 |

要点：
- 大数边界（`g4_float_boundary`：5335500×1.1、1624290×1.1、6726000×1.08、90×1.1 向上取整）在 LibreOffice 重算后得 5869050、1786719、7264080、99，与产出台相同：15 位有效数字的归整在 LibreOffice 里起作用。包另对这四格出 `excel_float` 告警（双精度直算会多 1）。
- `ceiling`、`floor` 的负数（-7 → 0、-50）、`rounddown`、`cumsum`、文字结果的 `if`、合计行按公式（101.5%）、平均值外包 ROUND（2504.38）都一致。
- 改代码前跑过一次，发现 2.0.1 原有的一处：百分比列的平均值，产出台按位数舍入为 5.8%（0.058），Excel 公式没有舍入（0.0575）。2.1.0 照精度口径 b 给合计行的平均值等也外包 ROUND，现已一致。
