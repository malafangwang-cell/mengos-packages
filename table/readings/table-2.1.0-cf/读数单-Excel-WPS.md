# 读数单 · 恒真条件格式（Excel、WPS；给本地施工方，在立法者电脑上测）

> 执行令《首发后-table包2.1.0》附录 A。样例工作簿：同目录 `cf-probe.xlsx`（XlsxWriter 3.3.0 生成，`make_probe.py` 可重新生成，两次逐字节相同）。
> LibreOffice 已在容器里测过，读数见 `读数-LibreOffice.md`（#4 不合：两条规则同时命中时不按属性合并）。

## 操作

1. 用 Excel 打开 `cf-probe.xlsx`，不要改任何格，逐行看 B、C 两列，把看到的底色、字色填进下表“Excel 实际”。
2. 第 6 行：选中 C2:C20，打开“开始 → 条件格式 → 管理规则”（显示其格式规则：当前选择），数一下里面有几条规则、各管哪个范围，填进表里。
3. 第 7 行：把 B3 改成 50，回车（Excel 自动重算；没有自动就按 F9），看 B3 的底色。
4. 关掉，不保存。用 WPS 表格重做 1–3 步，填“WPS 实际”。
5. 每一行截一张图，命名 `cf-<软件>-<编号>.png`，例如 `cf-Excel-4.png`、`cf-WPS-6.png`；第 6 行请把规则管理器一起截进去。

## 读数

| # | 格 | 设置 | 应显示（按 Excel 文档） | Excel 实际 | WPS 实际 |
|---|---|---|---|---|---|
| 1 | B2 | 只有静态格式：浅灰底 | 浅灰底 | | |
| 2 | B3 | 静态浅灰底 + 条件规则“> 100 标红底”命中 | 红底（规则压过静态） | | |
| 3 | B4 | 静态浅灰底 + 条件规则命中 + 一条恒真规则“浅灰底”排在最前 | 浅灰底（恒真规则压回） | | |

| 7 | 整表 | 改 B3 的值到 50 后重算 | B3 回到浅灰底 | | |
