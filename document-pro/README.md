# document-pro（文档追问Pro）

空的平台包：不带类型、渲染器、工具和包内规范（`types: []`、`tools: []`、`tools_lock.covers: []`，没有 `norms`）。只用来开通局部修改：工作区装了本包，并且本包对它可用（发布范围与授权没挡、没收回；计费开着时价目表里有本包），就可以对 `document` 包做出的产出发起局部修改。引擎判定见 mengosv2 `engine/server/local-edits/pro-gate.ts`。

## 前提

**需要先安装并启用“长文档编排”包（`document`）；单独安装没有作用。** 局部修改只能对“长文档编排”包的成型工具做出的产出发起，没装那个包就没有这种产出，本包装上也用不到。本版没有包依赖机制，安装本包时不会检查“长文档编排”包装没装，所以写在这里（立法者 2026-11-19“代价最小的方式”）。

## 说明

- **不需要、也不能启用**：本包既无工具也无规范，按 TL-31 E7 启用会回 409 EMPTY_PACKAGE。局部修改的判定只看装没装、能不能用，不看启用。
- **不走工具认证、不需要人签**：没有工具。
- **发布档要先签一次发布范围**：不带工具、没有范围记录的平台包，对还没登记的工作区不可见。平台管理员在发布范围页签一次 `open` 或 `granted` 后，商店里才看得到（mengosv2 首发部署清单第 57 条）。
- **开通费**：由运营定，可以为 0；引擎不看开通费。
- **content_hash**：口径同安装器（mengosv2 `engine/tools/package-hash.ts`）；清单计入，所以改任何一个字都会换 content_hash，须发新版本。
- 本页与清单里的 `title`、`summary` 只在商店展示，不进模型上下文。说明文字为草案，待立法者定稿。
