# subcontract-bom-generic（分包分解单规范（通用版））

纯规范平台包：只带包内规范（`norms`，17 TL-31），不带类型、渲染器和工具（`types: []`、`tools: []`、`tools_lock.covers: []`）。不走工具认证；装上后要等组织管理员签字启用才生效。`stage` 为 `beta`。

## 与企业版不要同时启用

本包是企业版 `subcontract-bom`（分包分解单规范，0.2.0）的通用版，两包条文大半相同，**不要同时启用**。同一工作区同时启用时，每次任务只会选中其中一个包，选中哪个事先说不准。测试与日常使用都一次只启用一个。

## 适用范围

适用于以结构件加紧固件为主、主件之下只有一级的产品，如货架、立库、钢平台、带构件表与节点详图的钢结构厂房（工程图须带构件表与节点详图或材料表，规格库可以只是型材、板材理论重量表）。**不覆盖输送线类装配产品**（以整机装配、电气与气动元件为主的），**不覆盖三级以上层级**；遇到时只列到主件下一级，并在问题表写明。除货架、立库外都未经真实样本验证，不称已验证通用。范围写在包说明里，不是条目。

不带任何一家企业的列名、编号格式与损耗系数：列名、表名与编号写法以组织规定为准，没有规定时用条文写明的默认做法；损耗系数没有规定时向发起人要。问题表写明本单所用的损耗系数及其出处，以及各项格式依据的是组织规定还是默认做法（R9.4）。

## 说明

- **条目**：`mengos-package.json` 的 `norms`，共 64 条（定义 11、约束 48、形态 5），体例“[定义|约束|形态] 正文”。条文由 work 侧交付，逐字照搬，打包时不改；与企业版的差别见 `变更说明.md`。
- **出处**：mengosv2 `docs/alignment/work交付/分解单规范-通用版-0.1.0/`（`norms.txt`、`meta.json`、`变更说明.md`）。评测材料不进本仓库。
- **核对条文**：`norms` 按序用换行连接、末尾加一个换行，即与来源 `norms.txt` 逐字节相同：
  ```
  python3 -c "import json,sys,hashlib; m=json.load(open('subcontract-bom-generic/mengos-package.json',encoding='utf-8')); print(hashlib.sha256(('\n'.join(m['norms'])+'\n').encode()).hexdigest())"
  ```
  0.1.0 应得 `b18f137761d0605125344dbd239f3fccc142190ee3b47392ff7e4a345b312665`。
- **content_hash**：口径同安装器（WP-W6 §2，mengosv2 `engine/tools/package-hash.ts`）与其他包的 `tools/make_package.py`；清单计入，所以改任何一条都会换 content_hash，须发新版本。
- **改条文**：任何一字都要发新版本，重新入册、安装核对，各组织重新签字启用。
